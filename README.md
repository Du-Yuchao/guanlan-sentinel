# 观澜 · SENTINEL

**智能体驱动的 AI 安全知识情报系统**，对应第三届“中国电子杯”高校 ICT 产教融合创新大赛赛题九。

本项目面向普通 Windows 电脑和离线答辩场景。围绕有来源的安全情报，完成采集任务编排、结构化富化、资产版本关联、知识图谱与引用式问答。默认采用本地证据检索，无须模型密钥。网页显示的数量由本地数据库计算。

> 当前交付是可运行、可检验的参赛工程版本。检索基线不等于大模型深度语义推理，离线回放不等于实时监测。赛事要求的准确率和召回率需要独立标注集证明，本项目不预先宣称达到获奖指标。

## 启动

环境要求：Node.js 22.12 或更新版本。本项目核心运行不依赖 npm 第三方包。

Windows 双击 **启动观澜.cmd**，或在本目录运行：

```powershell
npm start
```

浏览器打开 <http://127.0.0.1:8787>。首次启动会建立本地 SQLite 数据库并加载已核验资料快照。关闭终端即停止服务；已存储数据保留在运行目录。

## 三分钟体验

1. 在「情报总览」检查真实资料规模、类型分布和来源状态。
2. 点击「运行采集」，选择「离线回放」，查看各处理步骤及去重结果。
3. 在「情报探索」搜索 `CVE-2024-37032`，打开来源、影响版本及证据。
4. 在「资产影响」导入 `data/asset-example.json`，比较 Ollama 0.1.33 与 0.1.34 的结果。结论仅针对当前公告，不能将某条公告“不受影响”解读为资产整体安全。
5. 在「智能研判」询问“Ollama 和 llama-cpp-python 各有哪些风险？”，或“提示词注入有哪些防护建议？”。打开回答的引用。
6. 提问一个资料库不存在的 CVE，查看证据不足时的拒答。
7. 导出 Markdown 研判报告，保留本次分析的证据和运行记录。

## 数据和模式

- **已核验快照**：`data/verified_sources.json` 保存官方公告、研究论文、标准等公开来源的结构化摘要。摘要由人工核验整理，不冒充原文逐字引用。旧漏洞用于可重复验证，不展示为“今日新发现”。
- **离线回放**：对这些快照执行真实的规范化、去重、关联、校验和报告步骤，无须访问互联网。
- **联网采集**：适配器从公开来源请求数据。来源状态记录成功、失败及时间。固定标准/政策页面的更新检测与检索式新内容发现分开描述。
- **本地问答**：产品名、CVE、词项与领域同义词召回，结合证据生成结构化回答。跨文档引用是可检查的关联结果，不宣称通用自然语言推理。
- **可选模型问答**：配置后使用兼容接口处理证据上下文。需对配置的模型单独评测，不能直接沿用本地模式测试结果。

## 可选模型配置

将 `.env.example` 复制为 `.env`，在本机填写 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY` 后重启。密钥仅留在服务端环境文件中，不能放入网页、版本库或演示材料。当前验收默认不配置模型。

## 验证

```powershell
npm test
# 保持服务已启动，再开一个终端：
npm run evaluate
```

系统测试使用独立临时数据库。开发集验证结果输出至 `artifacts/evaluation.json` 和 `artifacts/evaluation.md`。这是少量公开构造用例的功能检查，不是独立准确率评估。

2026-10-17 验收：17 项自动化测试通过，7 个开发集用例通过；已在浏览器验证离线任务、双产品引用问答、详情、图谱和资产对照。

## 部署边界

默认只监听本机回环地址。本版本以单机研究演示为目标，没有实现多用户身份认证、租户隔离及互联网生产运维。如果使用 Docker，建议仅绑定 `127.0.0.1:8787`，持久化 `/app/data/runtime`。Dockerfile 是部署配置，构建结果须在有 Docker 的环境另行验证。
