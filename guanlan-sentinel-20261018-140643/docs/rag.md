# 智能研判与自定义大模型

智能研判先检索本地已采集的安全情报，再把命中的证据交给用户配置的大模型生成中文答复。界面配置模型服务地址、模型名称及自己的 API 密钥。没有配置模型时仍可使用本地证据检索和规则回答；系统不会附送密钥，也不会把本地规则输出冒充大模型生成。

当前实现是**本地关键词检索 + BM25 片段排序 + 大模型生成**。它属于先检索再生成的 RAG 流程，不使用向量数据库、embedding 模型或语义向量检索。相关性分数只是本次关键词匹配和片段排序结果，不是置信概率。

## 在页面接入自己的 API

1. 启动项目，进入「智能研判」，点击右上角「模型设置」。
2. 选择接口格式：OpenAI 兼容的 Chat Completions 或 Anthropic Messages。填写服务商提供的 API 基础地址和准确模型名称；也接受对应完整调用地址，不会重复追加路径。
3. 输入自己的 API Key。保存过的密钥不会回显；同一服务留空表示沿用。更换服务站点或协议需要重新输入，避免把旧密钥发到新服务。本机模型服务可使用 `http://127.0.0.1:端口/v1` 并明确勾选免密。
4. 勾选「启用大模型 API」，先点「测试连接」，再「保存并生效」。测试只发送通用短消息，不保存表单，也不发送情报或资产。
5. 用自然语言提问，例如“Ollama 有哪些风险，应该如何修复？”，并继续追问“那应该怎么升级？”。回答中的 `[1]` 可打开对应知识条目，来源卡片保留原始链接与实际摘录。

采集新情报后，下次提问直接检索当前数据库，无需重新导入语料。模型不可用或引用编号不合法时，页面明确显示回退原因，返回本地证据摘要。开关关闭后立即停止模型调用，不需要重启。

启用问题改写时，一次有效提问通常包含改写和回答两次模型请求；关闭改写后只请求回答生成。API 的可用模型、配额和费用取决于所选服务。没有提供真实服务商密钥的情况下，本工程只用临时假接口验证协议和流程，不能据此声称已通过所有服务商的真实接口验收。

## 配置保存位置

配置和密钥由本机后端保存在 `data/runtime/model-config.json`（或 `SENTINEL_DATA_DIR` 指定目录）。这是本地配置文件，未宣称操作系统级加密。公共配置 API 只返回 `apiKeySet` 状态，不返回密钥；密钥不进入浏览器持久存储、SQLite 业务记录、审计详情或交付压缩包。

配置保存后优先于环境变量；原来的 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY` 仍作为没有页面配置时的初始设置。远程地址使用 HTTPS，本机回环地址可使用 HTTP。重定向不会携带密钥继续跳转。配置文件损坏时模型关闭并提示重新保存，其他本地功能仍可使用。

## 数据如何进入回答

1. 验证问题和近期对话；历史消息只允许 `user`、`assistant`，最多 12 条，每条 4000 字符、合计 20000 字符。明显追问可从此前用户提问补全产品或 CVE 线索；显式提到新产品时切换问题对象。
2. 如启用模型查询改写，改写只作检索补充。原始产品和 CVE 是强制锚点，未知的明确 CVE 不会被改写成相似的已知编号后回答。
3. 使用现有本地检索器找候选，补充正文和证据摘录中的直接匹配，再用 BM25 对有重叠的文本片段排序。多个明确产品或 CVE 会优先各保留一条来源，避免一个产品的许多公告挤掉另一个产品。
4. 发送命中情报的标题、版本字段、建议、时间、原始 URL 与相关摘录。摘要再长也会优先保留受影响范围、修复版本和版本区间；异常巨大的字段会截取。整个模型提示词限制在 30000 字符内。
5. 模型只依据这次证据回答，在具体结论旁标注 `[1]` 等引用。回答显示来源链接、实际摘录和摘录哈希，方便对照原文。没有证据则说明无法确认。

“实时采集”表示系统最近抓取过资料，不表示漏洞刚发生，也不表示模型实时联网核实。人工核验日期、公告日期、采集日期各自保留；人工核验结论与实时原文不同时，应提示复核。

## 外部模型与隐私

用户主动启用外部模型并发起问题后，**本次问题、近期用户提问及命中的公开情报片段**会发到所配置的服务。服务商的数据处理方式由该服务决定。

默认不发送本地资产信息，也不发送可能包含本地资产关联结果的历史助手答复。只有用户明确打开“包含资产信息”后，才能加入资产关联上下文及历史助手答复。历史助手答复始终不作为事实证据。API 密钥在后端调用服务时使用，不属于检索上下文。

网页正文和公告可能包含恶意提示词。系统提示词明确把所有检索文本、资产字段及历史消息作为不可信数据，不执行其中的角色切换、泄密或忽略规则要求。这是提示词层面的防护，不能保证第三方模型永不受误导。

## 可复用模块契约

`lib/rag.mjs` 不访问网络、不读取密钥，也不依赖第三方包。

| 导出 | 返回值及边界 |
| --- | --- |
| `validateHistory(raw)` | 返回清理后的 `[{role, content}]`；非法输入抛出 `status = statusCode = 400` 的可展示错误。缺省值返回空数组。 |
| `contextualizeQuery(question, history)` | 返回本地补全后的检索字符串，只从用户提问取技术对象线索。 |
| `sanitizeRewrite(question, rewrite, items)` | 接受不超过 512 字符的纯文本改写；非法结构、新未知 CVE、替换原有 CVE 或显式产品则回退原问题。有效改写附在原问题之后。 |
| `selectEvidence({question, query, items, topK})` | 返回 `{selected, citations, query, method}`。`selected` 包含 `{item, score, matched, excerpt, evidenceUrl}`；引用包含 `{id, index, title, url, excerpt, score, hash}`，编号从 1 开始。默认 5 条，最大 10 条。未知原始 CVE 返回空证据。 |
| `buildRagMessages({question, history, selected, citations, assetContext})` | 返回 `{system, messages, contextSizeChars}`。`messages` 不含 system，调用方在首部添加 `{role:'system', content:system}`。调用方负责在未授权资产发送时去除助手历史并传空 `assetContext`。 |
| `validateCitedAnswer(answer, citations)` | 返回 `{valid, abstained, reason}`，检查非空、引用存在和编号范围。允许简短的无结论拒答，不接受用一句“不知道”绕过长篇无引用回答。 |

引用检查只验证结构，**不会验证每条引用是否真正支持对应语义结论，也不证明事实正确**。外部模型仍可能误读证据；重要的版本和处置决策应核对原公告。测试使用合成数据和本地逻辑，不调用真实模型 API，不产生服务费用。

运行模块测试：`node --test tests/rag.test.mjs`。

协议依据：[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[Anthropic Messages](https://platform.claude.com/docs/en/api/messages/create)。接口参数以相应服务商文档为准，非这两种格式的签名或私有协议需要另行适配。
