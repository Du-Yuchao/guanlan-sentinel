# 项目进度与续接位置

更新日期：2026-10-18。当前里程碑：离线工程版和实时采集故障恢复已验证，可在普通 Windows 电脑运行。此文件记录实际完成情况，避免额度中断后重复工作。

## 2026-10-18 智能研判 RAG 更新

- 「智能研判 → 模型设置」支持自行填写服务地址、模型名与 API Key，选择 OpenAI 兼容或 Anthropic Messages 协议，通用连接测试、保存即时生效、关闭即停止调用。本机模型可明确选择免密模式。
- 问答流程为本地情报候选检索、BM25 相关片段排序、可选模型问题改写、带引用生成与编号检查。支持有界多轮追问，原问题和已解析追问中的产品/CVE不会被改写替换；未知编号不会被类似公告补答。
- 新采集情报在下次提问时直接参与检索。影响范围、修复版本、时间和实际来源摘录进入证据上下文；API 失败或编号检查失败时明确提示并回退本地摘要。
- 配置和密钥保存于后端运行目录的独立文件；公共 API、审计和页面不回显密钥。默认只向所配置模型发送本次问题、近期用户提问与命中情报，不附带资产或旧助手回答。勾选资产发送后才允许加入相应上下文。
- 143 项自动化检查通过，覆盖两种协议、配置持久化、密钥脱敏、真实 HTTP 假模型端到端 RAG、追问对象、引用错误及故障回退。测试未使用真实服务商密钥，实际模型/配额/兼容性需用户在页面里测试。
- 已在浏览器核对设置表单、未保存连接测试失败提示、原有情报问答和实际来源引用。说明见 `rag.md`；设置预览见 `artifacts/rag-settings.png`。

## 当前启动与检查

双击项目根目录的 `启动观澜.cmd`，浏览器打开 `http://127.0.0.1:8787`。核心应用需要 Node.js 22.12 或更新版本，不需要模型密钥或 npm 安装。

系统测试：`npm test`。开发集检查：启动服务后运行 `npm run evaluate`。结果在 `artifacts/`。打包：`powershell -ExecutionPolicy Bypass -File scripts/package.ps1`。

运行数据库在 `data/runtime/`，不进入交付压缩包。已有的来源失败和运行历史保留，不可为了展示删除或改成成功。新解压的工程首次启动会重新建立数据库。
